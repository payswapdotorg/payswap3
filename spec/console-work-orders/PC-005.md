# PC-005 — Developer controls, credentials, webhooks, logs, and docs

**Status:** BLOCKED
**Depends on:** PC-004

## Files

- `src/app/console/developers/`
- `src/components/console/developers/`
- `src/lib/console/developers/`
- documentation content under the existing maintained application/docs convention
- focused developer-tooling tests

## Deliverables

Add API-key, webhook, request-log, request-inspector, environment, and documentation surfaces required by the frozen information architecture.

Credential operations use a dedicated server boundary. Environment scope is explicit. Creation, revocation, and audit semantics are preserved. Protected credential material must never appear in logs or request-inspector output.

Webhook delivery records reference existing event identifiers; retries must not imply duplicate financial effects.

Request logs distinguish transport/diagnostic data from protocol evidence. Documentation links resolve to maintained content and clearly label executable versus illustrative examples.

## Verification

Test role isolation, environment scope, creation/revocation behavior, protected-field redaction, webhook event references, and documentation route inventory. Run typecheck/build and focused tests.

## Stop

Stop if a credential operation would require direct access to a financial authority, or if the requested documentation contradicts the implemented protocol.
