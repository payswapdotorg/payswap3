# Obsolete Protocol Architecture Direction: PaySwap v0.2 Redesign

**Status: OBSOLETE — DO NOT IMPLEMENT**

The previously proposed protocol-level “v0.2 / Economic Intent Coordination Fabric” redesign was abandoned.

It does **not** supersede `spec/architecture/v0.1/`.

Implementation must continue against the frozen PaySwap v0.1 protocol architecture.

Product UX and deployment/operations may have their own contracts and versions, but those versions do not imply a new protocol architecture.

Do not use this obsolete proposal to:

- replace the v0.1 backend;
- remove existing v0.1 domains;
- remove netting, liquidity, credit, queues, capability emergence, agents, merchant primitives, evidence, recourse, simulation, federation, settlement or finality;
- create a new protocol kernel;
- reinterpret completed Work Orders.

Any future semantic protocol change requires a governed Architecture Change Request and a new immutable protocol architecture version.
