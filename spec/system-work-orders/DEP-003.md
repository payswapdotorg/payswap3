# DEP-003 — Durable persistence and work execution

**Status:** MERGED — b3bc430 (PR #9)
**Depends on:** DEP-001, DEP-002
**Owned surfaces:** database/queue/worker/scheduler integration, migrations, durable job state
**Forbidden:** duplicate financial authority; unsafe retries

## Objective
Provide durable, restart-safe work execution around existing protocol authorities.

## Acceptance
- Queued work survives process restart.
- Worker concurrency respects existing reservation/idempotency rules.
- Scheduler execution cannot duplicate financial work.
- Database migrations are explicit and verifiable.
- Persistent event/evidence state has a defined owner.
- Worker redelivery and restart are deterministic and safe.

## Required evidence
Restart/re-delivery tests, migration test, duplicate-work test, and queue durability proof.
