# SYS-001 — Three-architecture reconciliation

**Status:** BLOCKED  
**Depends on:** required UI and deployment items merged
**Owned surface:** cross-layer integration evidence and traceability
**Forbidden:** creating new financial authority or changing frozen protocol semantics

## Objective
Prove that consequential product journeys are backed by real protocol authorities and deployed through the intended runtime paths.

## Acceptance
For each major flow, trace product action → canonical protocol object/state → owning authority → API/runtime boundary → deployment component → durable state/evidence → user-visible outcome.

Prove no duplicate ledger/settlement/finality authority, no UI-only financial truth, no deployment bypass, explicit environment isolation, and preservation of UNKNOWN/waiting/recovery semantics.

## Required evidence
A deterministic reconciliation matrix plus automated checks for authority ownership, environment boundaries, and end-to-end state mapping.
