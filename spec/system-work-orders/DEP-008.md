# DEP-008 — Production readiness proof

**Status:** BLOCKED  
**Depends on:** DEP-006, DEP-007, product closure candidate
**Owned surfaces:** release-candidate operational verification
**Forbidden:** claiming production readiness from sandbox-only evidence

## Acceptance

On one exact release revision prove production-like protocol integration, UI integration, failure injection, scaling behavior, configuration/secret safety, backup/restore, queue recovery, UNKNOWN reconciliation, external-effect safety, rollback and observability.

## Required evidence

Immutable release identifier, complete verification transcript, failure-injection results, recovery transcript, security/configuration proof, and Architect approval.

## Stop conditions

Any unsafe external retry, environment crossing, missing recovery path, unreconciled UNKNOWN, configuration ambiguity or unexplained authority bypass.
