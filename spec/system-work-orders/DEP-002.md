# DEP-002 — Runtime packaging and configuration

**Status:** BLOCKED  
**Depends on:** DEP-001
**Owned surfaces:** runtime packaging, startup/readiness, environment validation, configuration handling
**Forbidden:** protocol semantics; plaintext secrets; production financial behavior in sandbox

## Objective
Make the application/runtime deployable with explicit configuration, safe startup, readiness and secret injection.

## Acceptance
- Deployment uses reproducible runtime packaging.
- Required configuration is validated at startup.
- Readiness fails closed when required infrastructure is unavailable.
- Secrets are injected through environment/deployment mechanisms, never source-controlled.
- Sandbox/demo and production configuration are explicitly distinguished.
- Health/readiness evidence is captured.
