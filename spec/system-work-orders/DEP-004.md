## Objective
Run durable operational processes for reconciliation, clearing, netting and settlement support through existing protocol authorities.

## Acceptance
- Jobs consume only authoritative protocol state.
- Duplicate execution is harmless or prevented by protocol concurrency controls.
- UNKNOWN external outcomes trigger reconciliation rather than blind retry.
- Clearing/netting jobs are restart-safe and auditable.
- Settlement-support work never asserts finality itself.

## Required evidence
Duplicate-job, restart, UNKNOWN, reconciliation and audit-evidence tests.
