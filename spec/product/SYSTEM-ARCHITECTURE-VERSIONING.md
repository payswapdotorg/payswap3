# Product-layer versioning boundary

Product documents may carry product-layer version labels such as `v0.2`. These labels are local to the product/UI/runtime layer and **do not denote a PaySwap protocol architecture version**.

The authoritative protocol architecture remains `spec/architecture/v0.1/`.

A product document must never be interpreted as permission to redesign, simplify, replace, or reinterpret the frozen protocol. Any semantic protocol change requires the repository's Architecture Change Request process and a new immutable protocol architecture version.
