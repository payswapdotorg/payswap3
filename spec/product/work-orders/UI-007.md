UI-007 — Liquidity, credit, and queue visibility surfaces

Status: PLANNED
Depends on: UI-006
Owned surfaces: read-only liquidity/credit/queued-position visibility surfaces for roles permitted by the owning protocol authorities; mapping records for these consequential states
Forbidden: protocol semantics; financial authority; bypassing protocol authorization; UI-side computation or origination of presented values; cross-role visibility leakage

Objective

Materialize read-only visibility of liquidity, credit, and queued positions: strictly presenting protocol-authoritative truth to the roles permitted to see it, with explicit UNKNOWN where authoritative answers are unavailable, and zero UI-side computation or origination.

Acceptance
Every presented value is a read-only presentation of state owned by a protocol authority; no value is computed, estimated, interpolated, or cached-as-truth UI-side (N1, P11).
Each visibility surface states whose authority owns the presented truth (visible provenance wording) (P11).
Indeterminate values render UNKNOWN with their reconciliation path — never as zero, empty, failed, or a definitive value (P5).
Role gating matches what the owning authorities permit: only permitted roles see each surface; deep links are role-checked (P8).
Progressive disclosure: headline positions first, composition detail one deliberate step away (P3).
Every consequential visibility state carries a complete nine-question mapping record (UX contract Section 8).
Where a position is consequential, its evidence trail is reachable (P7).
Accessibility and responsive baselines hold; dense position tables degrade to readable mobile forms rather than truncate or scroll horizontally (P9, P10).
Required evidence

Liquidity/credit/queue rendering evidence across states including UNKNOWN; role-gating proof; provenance-wording review; mapping-record review; accessibility and responsive spot evidence.

Stop conditions

Any requirement to compute or originate liquidity, credit, or queue values UI-side; any cross-role leakage; any UNKNOWN masked as a definitive value; any consequential state without a mapping record.
